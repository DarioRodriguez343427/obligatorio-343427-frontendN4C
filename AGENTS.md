# Contexto del proyecto

- Este repositorio contiene el frontend de AppGym, un proyecto académico para entregar en el curso de Desarrollo Fullstack.
- El frontend se construye desde cero con React y las librerías utilizadas en el curso.
- La carpeta hermana `../test clase 18` contiene lo realizado en clase. Consultarla como referencia para seguir las herramientas, los enfoques y el nivel del curso.
- La carpeta `obligatorio-frontend-343427` es el proyecto de entrega; realizar aquí los cambios de AppGym salvo indicación del usuario.
- Este frontend se vincula directamente con el proyecto backend tratado en el chat de ChatGPT llamado "aplicacion fullstack backend".
- No asumir que el contenido de ese otro chat está disponible: verificar las rutas, los contratos de datos y la autenticación con la documentación o el código disponible antes de implementar la integración.
- El trabajo continuará en distintos chats relacionados con este proyecto. Mantener estas pautas como contexto compartido.
- Comunicarse con el usuario en español.
